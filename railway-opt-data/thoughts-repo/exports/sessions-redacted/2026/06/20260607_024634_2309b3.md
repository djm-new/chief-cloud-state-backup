### 3. OpenAI OAuth

- Local Hermes metering is the source of truth for attribution.
- Provider reconciliation may be partial or unavailable.
- If exact billing reconciliation matters, prefer using a standard OpenAI API key for Hermes production calls instead of OAuth.

## The important design choice

Do **not** try to infer spend after the fact from transcripts.

Instead, instrument the **model-call boundary** in Hermes:

``​`text
Hermes request starts
  -> determine channel/project/session metadata
  -> call provider
  -> read response usage
  -> calculate estimated cost
  -> write usage event to SQLite
Hermes request completes
``​`

That way every model call is tracked, including:

- main assistant calls
- subagent calls
- compression calls
- vision calls
- cron jobs
- Slack monitors
- Telegram chats
- coding sessions
- tool-heavy loops
