## Important caveat

Slack Search API is not the same as literally reading every message in every channel. It searches the workspace visible to the token. For “entire business” coverage, I’d avoid relying only on search.

The robust design is:

- **Explicit channel allowlist** for guaranteed coverage of leadership/MENA/finance/revenue channels

- Later, add channels to the guaranteed list as we discover where important discussion happens
