# Weekly episode-first digest calibration

Session lesson: DJ rejected weekly audio that sounded like a theme essay, even when it used good audio and broadly relevant source material. The weekly product must be a podcast digest first: named episodes, guests, theses, and source-grounded takeaways.

## Required weekly structure

1. **Open with the named conversations.** Start by naming the primary people/episodes and their theses in plain language. If DJ specifies an intro, preserve its substance and order.
2. **Segment by episode, not abstract theme.** Each main block should begin with:
   - show name;
   - episode title;
   - guest(s);
   - publication/window status;
   - one-sentence thesis;
   - why DJ should care.
3. **Then extract arguments.** For each episode, cover the main claims, supporting examples, counterarguments, unresolved questions, and operator/investor implications.
4. **Use cross-episode synthesis only after episode grounding.** Comparisons and themes are valuable, but they should connect already-grounded episode segments rather than replacing them.
5. **Call out window exceptions.** If a calibration-positive episode is included from outside the strict Sunday–Saturday or last-7-days window, label it as a holdover/calibration pick rather than silently presenting it as in-window.

## Selection workflow

- Re-run collection/discovery/scoring for the requested week or last-7-days window before scripting.
- Use model scores as the funnel, not the final editorial answer.
- Query the episode database for named/expected guests before concluding they are absent.
- Fetch transcript-like page text for finalists where available; otherwise use episode pages/show notes/audio URLs as weaker grounding and mark the limitation.
- Keep a source-notes artifact beside the script listing selected episodes, links, evidence type, and any out-of-window exceptions.

## Script pitfalls

- Do not start with broad lines like “this week in AI/business...” unless immediately followed by named episodes.
- Do not summarize a topic without naming the show and guest responsible for the insight.
- Do not let the two hosts become generic analysts debating a theme; they are guiding DJ through specific conversations.
- Do not over-optimize voices before fixing editorial structure. If DJ says the audio is fine but the content is wrong, patch selection/scripting first.

## Verification checklist

- [ ] Intro names the top conversations and matches any user-provided framing.
- [ ] Every main segment starts with show + guest + thesis.
- [ ] At least the top 3 episodes have transcript/page-grounded notes.
- [ ] The script explains why each episode matters to DJ.
- [ ] The script includes arguments, examples, counterarguments, and implications—not just recap.
- [ ] Source notes disclose transcript availability and date-window exceptions.
- [ ] Final audio was rendered only after the script passes the episode-first check.
