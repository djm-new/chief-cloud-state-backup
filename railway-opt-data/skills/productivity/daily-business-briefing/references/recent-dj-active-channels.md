# Recent DJ-Active Channels

Use this when the Slack briefing needs to follow *your actual current work*, not just keyword hits.

## Core rule
If DJ has posted in a channel within the last 7 days, that channel should be treated as *high-priority context* even when individual messages are weak on keywords.

## What to look for
- Channels with direct DJ activity in the last 7 days
- Threads that continue from an active DJ conversation
- Channels tied to active ToM entities that DJ is currently touching

## Practical handling
- Build a recent-channel set from `from:me` / DJ-authored messages over a 7-day lookback.
- Reserve briefing capacity for those channels so they are not crowded out by keyword-heavy noise.
- Keep DMs/MPIMs always included, but do not rely on DMs alone to define work surface.
- Treat recent DJ-active channels as a *context lens*, not an automatic inclusion of every message.

## Good output behavior
- Surface at least one item from a recently active channel when there is any substantive signal.
- Preserve the channel label in the evidence so the reviewer can see why it stayed in scope.
- Prefer recent recency + channel history over generic keyword boosting when the two disagree.

## Pitfall
A pure keyword filter misses the real operating surface. If DJ has been active in a channel recently, that channel is probably part of the live business state even if the latest message looks mundane in isolation.
