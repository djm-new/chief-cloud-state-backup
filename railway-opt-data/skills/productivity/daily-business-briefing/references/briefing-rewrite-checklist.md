# Briefing rewrite checklist

Use this when DJ asks to *rewrite or improve an existing briefing using the same data*.

## Rules

- Do **not** rerun collection or refresh source data unless DJ explicitly asks for a new pass.
- Reuse the same archive or draft artifact as the source of truth.
- Collapse duplicate items into a single live section rather than repeating them across summary, action list, and carry-forward.
- Keep the executive summary to the top 3–5 truly highest-signal items.
- Put all action-like items into one consolidated action section.
- Move background-only items to monitor/carry-forward, not into the summary.
- Omit standing clutter sections like “deliberately excluded” unless DJ explicitly asks for exclusions.
- Rewrite in a direct, opinionated voice: say what matters and what to do next.
- When the user is reviewing the text, produce the revised artifact directly; do not narrate a plan.

## Quick quality check

Before finishing, ask:

- Is every top item new or materially important?
- Does any issue appear in more than one section?
- Can a busy reader act after one read?
- Does the draft feel shorter and sharper than the source?

## Recommended output pattern

- `Executive summary`: high-signal only
- `Action list additions`: all active decisions and follow-ups in one place
- `Worth knowing / monitor`: context only
- `Carry-forward context`: compact, non-duplicative state
