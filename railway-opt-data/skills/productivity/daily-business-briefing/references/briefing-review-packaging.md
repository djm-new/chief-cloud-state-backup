# Briefing review packaging

Use this when DJ asks for a briefing to be placed in a Google Doc or other review artifact for comments.

## Packaging rule

If the user asked for the *full* briefing, preserve the entire briefing body, including:
- the complete executive summary
- all action-list additions
- monitor / carry-forward sections
- appendix / links

Do not collapse the briefing into a summary-only excerpt unless DJ explicitly asks for a shortened version.

## Common pitfall

A “review doc” is not automatically a “summary doc.” If the source briefing had an appendix with links or source provenance, keep it in the review document so comments can target the full context.

## Verification

Before replying, confirm the doc preview or exported text still shows the same section structure as the archive/source briefing.
