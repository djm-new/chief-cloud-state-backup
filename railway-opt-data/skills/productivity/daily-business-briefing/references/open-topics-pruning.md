# Open Topics Pruning Checklist

Use this when `open_topics.md` starts carrying stale or duplicated items.

## Remove first

- Explicitly resolved or closed items.
- Dated items whose deadline has passed and no fresh update exists.
- Items that are now pure history and no longer need DJ action.

## Deduplicate

- Keep each topic in only one live section when possible.
- If an item appears in both carry-forward and pending decisions, decide which section is the active home and delete the duplicate.
- If an item is only context for another live item, compress it into that item instead of keeping a separate bullet.

## Keep

- Active blockers.
- Pending DJ decisions that still need action.
- Short-lived monitors with an explicit next check.

## Repair pattern

1. Read the file and identify stale bullets.
2. Remove the oldest dead items first.
3. Re-check section balance so the file stays compact.
4. Verify the result still looks like a live action surface, not a transcript.

## Practical note

When a user calls out stale content directly, treat that as permission to prune the file immediately and aggressively, while preserving any still-live decision points.
