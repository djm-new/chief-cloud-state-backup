# Memo formatting for DJ-facing onboarding docs

Use this structure when creating onboarding or transition memos for DJ:

- Title line
- Date subtitle directly under the title
- Blank line
- `Why this document`
- `What this role actually is`
- `Current state` sections grouped by function
- `Questions to answer early`
- `30/60/90 day focus`
- `Open deliverables`
- Closing note

## Style rules

- Keep the doc plain and readable; avoid decorative wording or overly clever framing.
- Prefer short headings and one-line bullets or short paragraphs.
- Lead with the business purpose and role ownership early.
- If the user says the formatting is wrong or references an existing memo style, rewrite to match that structure rather than layering on new sections.
- For interview-loop-adjacent docs, preserve the same cadence and hierarchy the user used before.
